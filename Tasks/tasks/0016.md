## 任務描述

Tim 2026-11-12：「幫工具接 Analytics」（前一句本小姐問他：曝光和留存要他從 Studio 截圖，還是幫工具接上 Analytics）。

**為什麼**：YouTube 運營觀察筆記（https://claude.ai/artifact/KTBj558QpT4JJrVsKGjcDN）的結論是「同一支片 B 站百位數、YouTube 個位數 ⇒ 先卡在沒被推薦出去」，但這只是推測 —— `senate cmd youtube` 只讀得到觀看、讚、留言，曝光、點閱率、留存、流量來源都讀不到。

**官方規格（2026-11-12 讀 developers.google.com）**
- YouTube Analytics API `GET https://youtubeanalytics.googleapis.com/v2/reports`：`ids=channel==MINE`、`startDate`／`endDate`、`metrics`，可選 `dimensions`、`filters`、`sort`、`maxResults`。回 `columnHeaders` ＋ `rows`（沒資料就沒有 `rows`）。
  - 指標有 views、estimatedMinutesWatched、averageViewDuration、averageViewPercentage、likes、shares、subscribersGained；留存 audienceWatchRatio、relativeRetentionPerformance（0.5 ＝ 同長度影片的中位數）。
  - ⚠ **沒有縮圖曝光與點閱率**（`adImpressions` 是廣告的、`cardImpressions` 是資訊卡的）。
  - 留存報表：維度 `elapsedVideoTimeRatio`，`filters` 一定要**單一**支影片。
  - 流量來源：維度 `insightTrafficSourceType`，可用 `video==` 篩一支。
  - 授權：`yt-analytics.readonly`；頁面另寫「API requests to this method now require access to the `youtube.readonly` scope」⇒ 兩個都要。
- 縮圖曝光與點閱率只在 YouTube Reporting API 的 reach 報表：`channel_reach_basic_a1`（維度 date、channel_id、video_id；指標 video_thumbnail_impressions、video_thumbnail_impressions_ctr）。
  - 流程：建 job（`jobs.create`）→ 48 小時內出第一份 → 建 job 會回補前 30 天 → `jobs.reports.list` → 用 `downloadUrl` 下載 CSV（一份一天）。報表留 60 天（回補的 30 天）。
- Cloud 專案（fir-demo-412cc）要另外啟用 **YouTube Analytics API** 與 **YouTube Reporting API**（跟已啟用的 YouTube Data API v3 是不同的 API）。

**Tim 要做的**（程式做完後）：啟用那兩支 API、資料存取權加兩個範圍、重跑 `op=login`。
