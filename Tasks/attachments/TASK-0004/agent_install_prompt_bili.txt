请帮我在这台 Windows 电脑上安装 Senate（https://github.com/tim099/Senate）。
我不懂技术，请你自己动手把下面的步骤做完，不要叫我开终端打命令。如果这台不是 Windows，直接告诉我目前只支持 Windows 就好。

1. 检查有没有 Git（2.25 以上）和 .NET 10 SDK（dotnet --list-sdks 要有 10 开头的那一行）。缺的用 winget 装：
   winget install --id Git.Git -e
   winget install --id Microsoft.DotNet.SDK.10 -e
   安装时 Windows 可能会弹出窗口问要不要允许更改，先跟我说一声，我会点「是」。
   刚装好的程序，你现在这个终端可能还找不到：请用完整路径调用，或把它们的安装文件夹临时加进这次命令的 PATH。
2. 把 Senate 下载到我的用户文件夹底下。那里如果已经有 Senate 文件夹，先停下来问我。
   git clone --recurse-submodules https://github.com/tim099/Senate.git
   一定要用 git clone，不要下载 ZIP。
   如果出现「Filename too long」，是文件夹的路径太长：把刚才没下载完的那个 Senate 文件夹删掉，改下载到短一点的位置（例如 C:\Senate）再做一次。
3. 用 Git 自带的 bash 执行安装脚本（bash 通常在 C:\Program Files\Git\bin\bash.exe）。下面的「Senate文件夹」换成第 2 步下载到的完整路径，用正斜线写（例如 C:/Users/名字/Senate）：
   bash.exe -lc "cd 'Senate文件夹' && ./install.sh"
   第一次要编译，会跑几分钟，请等它跑完。
4. 看脚本最后打印出来的结果。失败时它会打印一行 ✗ 说明原因，请照那一行处理后重跑；处理不了就停下来，用大白话告诉我卡在哪里，不要自己想办法绕过去。
5. 成功之后，执行 Senate 文件夹里的 publish\senate.exe doctor 确认环境正常，然后用大白话告诉我两件事：
   ・Senate 装在哪个文件夹
   ・接下来怎么开始用：重新开一个 agent 窗口，把工作文件夹选成 Senate 那个文件夹，对它说「早安大小姐」
   安装时自动启动的后台程序是 Senate 自己要用的，不用关掉。
