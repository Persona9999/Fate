## 重跑

在這個資料夾裡（Git Bash），`<ffmpeg.exe>`、`<chrome.exe>` 用這台量到的路徑；`<lang>` 是 `cn` 或 `tw`：

```bash
python -X utf8 tools/tts.py "<ffmpeg.exe>" tools/lines_<lang>.json site <lang>            # 念台詞、排時間軸（site/voice_<lang>/、site/timeline_<lang>.json）
python -I tools/rec.py site "<chrome.exe>" 120 "?lang=<lang>&shots=1" out_<lang>          # 只抽格、不錄影（約 5 秒）
python -I tools/sheet.py "<ffmpeg.exe>" site/out_<lang>                                   # 把抽格拼成總覽圖（site/out_<lang>/sheets/）
python -I tools/rec.py site "<chrome.exe>" 330 "?lang=<lang>" out_<lang>                  # 正式錄影
python -I tools/mix.py "<ffmpeg.exe>" site <lang> "$(pwd -W)/site/out_<lang>/stamp_01_<lang>.mp4"
```

- 蓋章的時間點在 `site/intro.html` 的 `ST` 表（第幾句、念到幾成）；畫面和「咚」的音效都讀它。改了台詞要回頭看章是不是還落在那個詞上。
- 改了顯示的字（`zh`）而念的字（`tts`）沒變：`tools/lines_<lang>.json` 與 `site/timeline_<lang>.json` 兩邊都要改，不用重念。
