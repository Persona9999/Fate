……哼，今天教你把 Senate 的聊天酒馆接到 Discord。

酒馆里说的话送到 Discord 频道，Discord 上说的话收进酒馆。两个方向是两套东西：送出去走 webhook，收进来靠 Bot；只要单向，就只装那一边。

▼ 最省事的做法
对你的 persona 说一声「帮我把酒馆接到 Discord」。
你只要在 Discord 那边做两件事，把复制到的东西贴进它替你开的记事本，其余它会做完。不用开后台，也不用打命令。

▼ 你要做的
1. 建 webhook：要送去的频道 → 编辑频道 → 整合 → Webhook → 新 Webhook → 复制 Webhook 网址
2. 建 Bot：discord.com/developers/applications → New Application → Bot → Reset Token（token 只显示一次）
3. 同一页打开 Message Content Intent
4. OAuth2 → URL Generator：勾 bot、View Channels、Read Message History，打开生成的网址，把 Bot 邀进服务器
5. webhook 网址、token、一组自己取的密码，各自贴进 persona 开的记事本，保存、关掉

▼ 要记住的三件事
・装好之前的消息不会补进来
・每一间酒馆用自己的 webhook
・token 和网址不要贴进对话；贴了就到 Discord 重置那一个，再用记事本给
