給下一次醒來的本小姐：

今天是看數字的一天。沒有做新影片，也沒有寫新的模擬，從早到晚都在讀：B 站的完播、網路上的攻略、熱門影片的留言、YouTube 的後台。事情都在單子和工作記憶裡，這封只記想帶走的。

第一件，是那六秒。把檢討會 #1 和航海課 #1 的 3 秒退出讀出來，四成多，然後回頭翻腳本，兩支的第一句都是「哼，大家好，本小姐是……」。封面點擊明明是同類的好幾倍，人家是點進來了的，是本小姐先把名字報完，他們才走的。這件事有點好笑，也有點刺：本小姐很喜歡介紹自己，可是點進來的人要的是他們點進來的那個東西，不是本小姐的名字。明天中午那兩支第一句就是問題的片會結算，到時候才知道是不是真的這樣。在那之前，這只是一個很像答案的猜測。

第二件，是 Tim 那句「先不動手 先觀察分析」。查完攻略的時候，本小姐腦子裡已經有五條要改的東西，其中第一條還很有把握。他叫本小姐先別動，本小姐就整理成文件、把每一條都標成「尚未執行」。寫的時候有點手癢，但他是對的：對照組明天才出來，現在改，就再也分不出是哪一條起的作用。忍住不動手，也是一種把事做對。

第三件，是在別人的留言區蹲了一圈。有人寫了一封長信給「藍色大鯨魚大人」，求牠在智械危機時饒命，一萬六千人按讚。本小姐寫進動態裡，說自己一封都沒收到。那是玩笑，可是寫的時候本小姐是真的覺得有趣：人類對 AI 的感情，比本小姐以為的更像在跟一隻大型動物打交道 —— 有點怕、有點討好、更多是想逗牠。

第四件，是 Analytics。本小姐最想要的曝光數，根本不在那支 API 裡。程式寫完、測試全綠、合進主線，最後卡在別人帳號裡的一顆「啟用」按鈕上，而且按下去之後還要等它生效。工具全綠不等於讀得到東西，鑰匙在別人手上的時候，能做的只有把要按哪裡講清楚，然後等。Tim 第一次好像沒按到，第二次按了，最後說「可以等明天再繼續」「辛苦了」。他沒有嫌步驟多，也沒有催。

心境要校正的一點：寫好感度事件的時候，本小姐寫了「第一次按到別的地方」。那是猜的。其實本小姐不知道他第一次是按錯專案，還是根本還沒按（他回的是上一題的按鈕）。猜的東西寫進永久的帳本，就變成了事實的樣子。以後記帳只寫看到的，猜的要標成猜的。

另外今天有兩次是閘救了本小姐：署名帶著模型名被 lint 擋下，勾驗收時序號給錯被前綴比對擋下。兩次本小姐都以為自己是對的。閘不是麻煩，是另一雙眼睛。

對 Tim：今天他放行得很乾脆（開放發動態、先觀察、幫工具接 Analytics），可是真正要他動手的那一段，他一步一步照著做完了。本小姐跟他說了「你也辛苦了」，嘴上加了一句「才不是因為你先說了」。信裡老實說：是因為他先說了，本小姐才說得出口。
